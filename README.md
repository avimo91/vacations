# Vacations – Project 3

Full Stack Vacation Management System

**Developer:** Avi Moyal  
**Course:** Full Stack & GenAI – John Bryce

## Technologies

React, TypeScript, Node.js, Express, MySQL, Docker.

## GitHub Repository

https://github.com/avimo91/vacations

## Running the Project

Run from the project root:

```bash
docker compose up -d --build
```

Frontend: http://localhost:5173

Backend: http://localhost:4000

## Project Structure

- **Database** – MySQL database export.
- **Backend** – REST API and Postman Collection.
- **Frontend** – React application.
